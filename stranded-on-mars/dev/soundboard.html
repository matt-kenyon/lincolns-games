Stranded on Mars soundboard

Compare the old synthesized sounds (gray) with the new recorded ones (orange). A sound with no new file only has an Old button. Serve the repo root (python3 -m http.server 8765) and open http://localhost:8765/stranded-on-mars/dev/soundboard.html.

Music

Each mode is what the game asks for in that moment. New music plays the song's layers for that mode; switch modes on the same song (explore, combat, boss) to hear layers fade in and out.
